# جورنالي

تطبيق أندرويد (APK) شخصي لتعمير الجورنال اليومي للمعلّم تمام مرزوقي — المدرسة الابتدائية السواني — 2026-2027.
يخدم **بلا إنترنت وبلا أي API**: قراءة المخططات، تعمير الجورنال، وتوليد ملف Word، كلّو داخل التلفون.

## التحميل والتثبيت
1. من التلفون افتح الرابط: **https://github.com/marzouguitammem-cmd/journali/releases/download/apk/journali.apk**
2. افتح الملف `journali.apk` اللي تحمّل. إذا طلب، اسمح بـ «تثبيت تطبيقات من مصادر غير معروفة» للمتصفّح (Chrome).
3. ثبّت وافتح «جورنالي».
4. كل نسخة جديدة تتثبّت **فوق** القديمة من نفس الرابط، ومخططاتك وجورنالاتك يقعدو.

## الاستعمال
- **المخططات**: لكل مادة في الجورنال «➕ زيد مخطط» واختار ملف Word أو PDF من التلفون. التطبيق يقراه وحدو، يوريك الحصص، وتحفظ.
  مخططات الفترة الأولى (رياضيات س5 و س6، إيقاظ علمي س5) موجودين من الأول.
- **الجورنال**:
  - «⏭ اصنع جورنال النهار الجاي»: التطبيق يعرف وين وصلت في كل مادة ويعمّر بالدروس الموالية.
  - «جورنال بأرقام الدروس»: تختار النهار وتكتب رقم الدرس لكل نشاط.
- **تعديل الجورنال**: «🔁 بدّل الدرس» في النشاط اللي فيه غلطة. «هدف الحصة»: ✨ صياغة أخرى، 🗑 فسخ، أو اكتب بيدك، و«💾 احفظ في المخطط» باش يقعد للمرّة الجاية.
- **التصدير**: «📤 شارك» (واتساب، Drive…) أو «💾 حفظ في الهاتف» (Documents/جورنالي). الملف صفحة وحدة A4 بالعرض، بنفس تصميم `examples/saturday_example.pdf`.
- **وين وصلت**: التقدّم في كل مادة، مع إمكانية التقديم والترجيع بيدك.
- **الإعدادات**: توزيع المواد الأسبوعي، ونسخة احتياطية.

## للمطوّر
- `app/`: React + Vite + TypeScript، ومغلّف أندرويد بـ Capacitor (`app/android`).
- `app/src/journal/docx.ts`: نقل حرفي لـ `generator/make_journal.js` (يعطي نفس الملف بالضبط).
- `app/src/plans/`: قراءة المخططات (Word عبر JSZip، و PDF عبر pdf.js + تحليل رسم الصفحة لاكتشاف الخانات المدمجة).
- `data/lessons.json`: بنك الفترة الأولى (أهداف الحصص مصاغة مسبقاً).
- البناء: كل push يشغّل `.github/workflows/build-apk.yml` اللي يبني الـ APK وينشرو في Releases تحت الوسم `apk`.
- تجارب محلية: `cd app && npm run dev`، ثم `node scripts/test-parse.mjs <مخطط>` و `node scripts/ui-test.mjs <مجلد>`، و `npx tsx scripts/sample.ts ../examples/saturday.json out.docx`.
